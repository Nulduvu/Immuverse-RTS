# Immuverse RTS

a single player RTS game inside a human body

## Description

it's a single player RTS game where players play as the immune system of a person sick.
the project has been developed in python using pygame for the trophees nsi of 2026.

## Getting Started

### Installing
* there is no installing required to play the game
### Where to play
* you can play on GitHub pages

## Help
if the game didn't start :
* try reload the page

if you encouter any problem during the game or if the game still didn't start after reloading :
* add /#debug after the URL
* take a screenshot
* report your bug in Issues with the screenshot
* we will come help you if we can
